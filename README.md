# public-record-benchmarks

Reproducible DuckDB, HTTP latency, and schema benchmarks for public federal contracting, SEC EDGAR, open-FDA, and software supply-chain datasets published across **[LiveAgentData](https://liveagentdata.com)**, **[OffMarketSaaS](https://offmarketsaas.com)**, and **[AgentWhitelist](https://agentwhitelist.com)**.

```bash
python3 scripts/bench.py
python3 -m unittest discover -s test
```
